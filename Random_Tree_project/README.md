The present project will implement three classical sample
methods in three different maps, these methods are Rapidlyexploring
Random Tree (RRT), Optimal Rapidly-exploring
Random Tree (RRT-start) and Rapidly-exploring Random Tree
Connected (RRT-connect). Besides, as a novel contribution
we will adapt the RRT with adaptive goal biasing, as a
new method to show. Finally, we present the results for
different parameters and we will make a comparison of the
four methods.
