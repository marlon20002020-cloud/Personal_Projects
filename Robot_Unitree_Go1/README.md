This project explores the implementation of biologically inspired gaits on the Unitree Go1 robot, focusing on the walk, 
trot, canter, and gallop gaits. Quadrupedal locomotion requires coordinated timing of swing, stance, and transition 
phases across four independent legs. Each gait was analyzed in terms of duty cycle, phase offsets, and limb 
coordination to create a programmable framework for generating stable and efficient robotic motion. This report 
documents the gait modeling process, presents timing diagrams for each locomotion pattern, and establishes the 
structural foundation for trajectory generation, control system integration, and real-world deployment of the Go 1 
robot. In the lab, we achieved all four gaits that are capable of walking without falling over. The walk gait also features 
an IMU-based yaw-correction controller, which keeps the robot walking into a new line.
